        Try it out

        It grades its own free signals.

        Every company is also scored from free data alone and compared with what its licensed headcount did. That is how Trace knows where free data is weakest, and where to spend.

        In a 10-company sample, free data alone got five wrong. It called Spade quiet while its headcount doubled.
        • Many startups never file a Form D, so a filing is a badge, never a status.
        • The Web Archive crawls popular sites more often. Each source is capped per month so one cannot dominate.
        • Fading is a trend, not a prediction. It has not been backtested against outcomes yet.
        • Common names collide. An exact name without a matching city or state goes to review instead of linking automatically.

        Run it on your own portfolio.

        Point it at your fund's public portfolio table. It pulls the companies, checks every source, asks you to confirm the matches it wasn't sure about, and writes the census as HTML, JSON and Markdown.

        Get the code on GitHub Try it out → 
        pip install -r requirements.txt
cp .env.example .env             # set SEC_USER_AGENT; the Claude key is optional
python3 -m src.cli init          # the fund's portfolio table, into SQLite
python3 -m src.cli sync          # domains, website, GitHub, job boards, SEC
python3 -m src.cli review-queue  # confirm or reject uncertain matches
python3 -m src.cli score         # statuses, printed as a table
python3 -m src.cli export        # exports/census-<date>.{html,json,md}

        Every raw response is kept in data/raw/<source>/<date>/, and every observation points to the dump it came from.
