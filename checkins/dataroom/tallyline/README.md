# Tallyline HQ

> Synthetic company for the Deal Flow hackathon demo. Every person, number and company here is invented.

Tallyline is the internal source of truth: strategy, meetings, plans and the exports from our systems. Investors never see this folder directly. Our check-in agent answers their questions from it, and a founder approves every answer before it is sent.

| Folder | What's in it | Verification tier when cited |
|---|---|---|
| `systems/` | Monthly exports from Stripe (billing) and Mercury (bank) | Verified |
| `company/`, `strategy/`, `finance/`, `hiring/`, `product/`, `customers/`, `meetings/` | Docs the team writes | Documented |
| `investor-updates/` | What we already sent investors | Documented |
| `people/` | Confidential. Never shared, see `agent-policy.md` | Not shareable |
