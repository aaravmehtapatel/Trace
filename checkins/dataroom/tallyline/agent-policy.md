# Check-in agent policy

Written by Dana Okafor (CEO), 2026-03-02.

1. Answer only what an investor asked. Don't volunteer documents.
2. Every answer cites the file it came from. If no file supports it, say so plainly. Never guess or fill gaps.
3. Never share anything in `people/`: individual salaries, equity grants, performance notes.
4. Customer names may be shared with our lead investor (Northbeam) only. For anyone else, describe the customer ("a 34-location restaurant group").
5. Nothing is sent until Dana or Priya approves it.
